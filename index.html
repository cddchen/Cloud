⚡ 快速部署与连接指南 (Quick Start)

第一步：在电脑或工作站启动 Host 服务

需要 Node.js >= 22。在您的项目服务端目录配置安全 Token 并运行： 

export HOST_AUTH_TOKEN="your-secure-token"
export HOST_PORT=3000
node dist/index.js --port 3000

第二步：移动端配对连接

打开手机端 Cloud App，在“连接设置”输入您的 Host 地址（如 http://192.168.1.100:3000 或 Tailscale 节点）及预设 Token，点击“测试并连接”即可完成同步。

❓ 常见问题解答 (FAQ)

Q1: 为什么移动端提示“连接失败”或“请求超时”？ +
请检查以下三项：
1. 网络连通性：手机与服务端需处于同一局域网 Wi-Fi，或已接入 Tailscale 等虚拟内网；
2. 防火墙放行：确保宿主机防火墙未屏蔽对应端口（默认 3000）；
3. 本地网络权限：iOS 用户请前往系统“设置” -> “隐私” -> “本地网络”，确认已授予 Cloud 权限。
Q2: 提示“鉴权失败 (Authentication Failed)”怎么处理？ +
移动端输入的访问 Token 必须与服务端启动时通过 HOST_AUTH_TOKEN 环境变量设置的字符串完全匹配。请检查有无误复制前后空格。
Q3: 手机离开 App 或锁屏休眠，长耗时任务会中断吗？ +
不会。 服务端持有 Agent 的完整独立运行时，长耗时任务会在后台持续平稳执行。移动端恢复前台后，系统会自动重连并拉取最新状态增量，无缝对齐最新进度。
Q4: 数据安全与隐私保障机制是怎样的？ +
Cloud 坚持纯私有端到端直连设计。您的源码、命令提示词与会话历史仅在您的手机与您自己的私有 Host 之间传输，不存在任何收集、解析或存储您代码的第三方中间服务器。
