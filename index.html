⚡ Quick Deployment & Host Setup

Cloud utilizes a direct client-to-host architecture, connecting via Public Network, LAN, or Tailscale Mesh. Data streams directly via the Claude Agent SDK without passing through third-party services.

Step 1: Start the Host service on your workstation or VM

Requires Node.js >= 22 and Claude Code. You can authenticate Claude Code via official subscriptions (Pro/Team) or custom third-party API keys and proxy endpoints (e.g. ANTHROPIC_API_KEY, ANTHROPIC_BASE_URL). 

# 1. Start via CLI parameters (default port: 8787, random 6-digit token)
npx @cddchen/cloud@latest start --port=8787 --token=your-secure-random-token --global

# 2. Or configure via environment variables
export HOST_AUTH_TOKEN="your-secure-random-token"
export HOST_PORT=3000
npx @cddchen/cloud@latest start --global

Step 2: Connect from Mobile Device

Open Cloud on your mobile device, navigate to "Connection Settings", enter your Host address (e.g. http://192.168.1.100:8787 or Tailscale node) and token, then tap "Test & Connect" to synchronize.

⚡ 快速部署与连接指南

Cloud 采用客户端-服务端直连架构，通过公网/局域网/Tailscale组网等形式直连宿主机，基于 Claude Agent SDK 直接传输数据，不通过任何第三方服务。

第一步：在电脑或工作站启动 Host 服务

环境要求 Node.js >= 22 与 Claude Code。支持使用 Claude 官方订阅账号（Pro/Team 等）在主机端登录，或通过环境变量配置第三方 API Key / 反向代理网关（如 ANTHROPIC_API_KEY、ANTHROPIC_BASE_URL）。 

# 1. 通过命令行工具参数启动（默认端口 8787，默认随机 6 位数 Token）
npx @cddchen/cloud@latest start --port=8787 --token=your-secure-random-token --global

# 2. 通过环境变量设置
export HOST_AUTH_TOKEN="your-secure-random-token"
export HOST_PORT=3000
npx @cddchen/cloud@latest start --global

第二步：移动端配对连接

打开手机端 Cloud App，在“连接设置”输入您的 Host 地址（如 http://192.168.1.100:8787 或 Tailscale 节点）及设置的 Token，点击“测试并连接”即可完成同步。

❓ Frequently Asked Questions (FAQ)

Q1: Why does the mobile app display "Connection Failed" or "Timeout"? +
Please verify the following:
1. Network Connectivity: Ensure your mobile device and host are on the same Wi-Fi network or interconnected via Tailscale/WireGuard.
2. Firewall Rules: Check that your host firewall allows inbound connections on the listening port (default: 3000).
3. iOS Local Network Permission: On iOS, open Settings -> Privacy & Security -> Local Network, and ensure permissions are granted to Cloud.
Q2: What should I do if "Authentication Failed" occurs? +
The token entered in the mobile app must strictly match the HOST_AUTH_TOKEN environment variable configured on the Host. Please check for accidental whitespace or newline characters.
Q3: Will long-running agent tasks abort if the phone locks or goes to background? +
No. The Host server maintains the authoritative agent runtime and lifecycle. Complex coding and tool executions continue smoothly in the background. When the app returns to the foreground, it seamlessly catches up with the latest progress.
Q4: How does data privacy and security work? +
Cloud is engineered with an end-to-end direct private architecture. Your codebase, prompt instructions, and chat sessions stream exclusively between your mobile device and your private Host. There is zero telemetry, no ad tracking, and no intermediary cloud inspection.
Q5: Is Claude Code mandatory on the Host? What authorization methods are supported? +
Yes. Cloud Host fundamentally relies on a functional Claude Code environment on the host.
Flexible Authorization:
1. Official Subscription: Log in directly with your Anthropic Claude Pro / Team / Enterprise account on the host;
2. Third-Party API / Proxy: Fully supports configuring custom API keys and proxy URLs via environment variables (such as ANTHROPIC_API_KEY and ANTHROPIC_BASE_URL), without restrictions from official web subscriptions.

❓ 常见问题解答 (FAQ)

Q1: 为什么移动端提示“连接失败”或“请求超时”？ +
请检查以下三项：
1. 网络连通性：手机与服务端需处于同一局域网 Wi-Fi，或已接入 Tailscale 等虚拟内网；
2. 防火墙放行：确保宿主机防火墙未屏蔽对应端口（默认 3000）；
3. 本地网络权限：iOS 用户请前往系统“设置” -> “隐私与安全性” -> “本地网络”，确认已授予 Cloud 权限。
Q2: 提示“鉴权失败 (Authentication Failed)”怎么处理？ +
移动端输入的访问 Token 必须与服务端启动时通过 HOST_AUTH_TOKEN 环境变量设置的字符串完全匹配。请检查有无误复制前后空格。
Q3: 手机离开 App 或锁屏休眠，长耗时任务会中断吗？ +
不会。 服务端持有 Agent 的完整独立运行时，长耗时任务会在后台持续平稳执行。移动端恢复前台后，系统会自动重连并拉取最新状态增量，无缝对齐最新进度。
Q4: 数据安全与隐私保障机制是怎样的？ +
Cloud 坚持纯私有端到端直连设计。您的源码、命令提示词与会话历史仅在您的手机与您自己的私有 Host 之间传输，不存在任何收集、解析或存储您代码的第三方中间服务器。
Q5: 主机端必须使用 Claude Code 吗？支持哪些授权方式？ +
是的。 Cloud 服务端运行深度依赖本机已配置好的 Claude Code 环境。
授权方式高度自由：
1. 官方订阅：直接在主机端使用 Claude 官方 Pro / Team / Enterprise 订阅账号登录；
2. 第三方 API / 代理：完全支持配置您自己的第三方 API Key 或中转网关（配置环境变量如 ANTHROPIC_API_KEY、ANTHROPIC_BASE_URL），不受官方网页端限制。
